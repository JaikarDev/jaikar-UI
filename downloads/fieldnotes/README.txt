FIELDNOTES — SPATIAL INVESTIGATOR
Unity Windows Portfolio Prototype

Created by Jaikar Pothula / Jaikar Studio
Portfolio: https://jaikarpothula.com

SYSTEM REQUIREMENTS
- Windows 10 or Windows 11, 64-bit
- Keyboard and mouse
- A graphics card that supports DirectX 11 or DirectX 12

HOW TO RUN
1. Extract the entire ZIP file to a folder.
2. Keep Fieldnotes.exe beside Fieldnotes_Data and the other included folders.
3. Double-click Fieldnotes.exe.
4. If Windows SmartScreen appears, inspect the publisher/file details and choose to run only if you trust this portfolio build.

WHAT TO TEST
- Select the brass key, field recorder, and sealed letter.
- Rotate and zoom the active clue.
- Add evidence to Connections.
- Review the case timeline and case notes.
- Open Settings and test reduced motion.
- Close and reopen the experience to verify saved evidence state.

BUILD INFORMATION
- Unity Editor: 6000.3.10f1
- Render pipeline: Universal Render Pipeline (URP)
- Platform: Windows x86_64
- Build type: Desktop portfolio prototype inspired by spatial computing and visionOS interaction principles

VERIFIED
- Built with zero Unity build errors.
- Launched and visually checked outside the Unity Editor.
- Evidence selection, saved connections, case notes, navigation, and reduced-motion settings were tested in the Unity Editor.

CURRENT SCOPE
This is the exact Windows desktop prototype shown in the Fieldnotes case study. Native PolySpatial integration, gaze-and-pinch interaction, Xcode export, and Apple Vision Pro hardware validation remain future work. Apple does not sponsor or endorse this independent portfolio project.
